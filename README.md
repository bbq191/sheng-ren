# 电子书入库与按阅读模式优化工具

在电脑上把 EPUB 和 CBZ 漫画收进一个**书库**，按三台阅读器各自的特点**生成适合它的书**（Kindle 出 KFX，掌阅、Move 出 EPUB），`booklib sync` **直接传到接着的设备上**，电脑上不留产物。

![总体流程](docs/img/overview.svg)

- **收书**：EPUB、CBZ 漫画、网页链接。书库**只存索引**（原件在哪、内容哈希、书名作者），不复制原件。同一本书重复入库、改名、挪位置都认得出。
- **文字书只修复**：修成合规的 EPUB 3、修目录（按书/卷、章、节嵌套，漏掉的节补进目录），**文字、图片、格式、样式一概不动**，也不拆原书的章节文件。各台另加一点：Kindle 由 KFX 写出器照 Send to Kindle 的规则排；掌阅、Move 照同一套规则补标签缺省样式、正文用阅读器字体等；Move 另外保证注释点得动。
- **漫画**：保留原画质，按阅读器真正能显示的范围缩放、补白，图离屏幕边缘 1px；黑白屏转 256 级灰度（不抖动）。
- **补封面和简介**：联网找简介、标签（豆瓣 → QQ 阅读 → Wikidata）；没封面的书顺带找封面（豆瓣 → QQ 阅读 → 原作封面 → 都没有就生成一张）。只补进产物，原件不动。
- **跟着书目录走**：登记一次书目录，之后新增、改过、挪过、删掉的书自动同步（书库严格镜像书目录），只重建、只重传有变化的；原件删了，设备上那份也删。

> 底线：书里的文字一个不多、一个不少；图片还是原来那张，只为适配屏幕缩放；拿不准的就不处理。

## 快速开始

需要 Rust 工具链（`cargo`）。

```sh
./install.sh                                  # 安装 booklib（详见使用指南 · 安装）
booklib track ~/Documents/ereader/books       # 登记书目录（只需一次）
booklib sync                                  # 同步进书库，为接着的设备生成并传上去
booklib list                                  # 看每本书在各设备上的产物、是不是最新
```

产物直接放到设备上：Kindle、掌阅（USB）放存储根目录的 `documents/<子目录>/`，Move 经 SSH 加进它的书库、按子目录建文件夹；没接上的设备这次跳过，下次接上再传。见[使用指南 · 产物放在哪](docs/usage.md#产物放在哪)。

## 三个阅读模式

| 模式 | 给谁读 | 产物 |
|---|---|---|
| `kindle` | Kindle Paperwhite 12 代签名版自带阅读器 | KFX |
| `ireader` | 掌阅 Ocean 5 Pro 自带阅读器 | EPUB |
| `xochitl` | reMarkable Paper Pro Move 自带阅读器 | EPUB（彩色） |

三个模式用同一套代码，区别（屏幕、阅读范围、阅读器的怪癖、各台另加的规则）都写在模式的配置里，见[设备与阅读模式](docs/devices.md)；每个模式对书做了什么见[排版与优化规则](docs/typesetting.md)。

## 几个词

| 词 | 意思 |
|---|---|
| 书库 | 电脑上的一个目录（缺省 `~/.local/share/booklib`），只记原件在哪、内容哈希、书名作者、找来的封面 |
| 阅读模式（profile） | 一种阅读器的参数：屏幕、可阅读范围、黑白还是彩色、产物格式、注释怎么处理、怎么传到设备。一个模式出一份产物 |
| 可阅读范围 | 阅读器除去页边距、页眉页脚后真正显示内容的区域 |
| 产物 | 按某个模式生成的书，直接传到设备上（电脑上不留） |
| 指纹 | 决定产物要不要重建的一串值，其中任何一项变了才重建 |
| 质量门 | 产物生成后的自检（XHTML 合法、引用都找得到、没有 DRM）；不过只警告 |

## 现状

- 漫画三台都在真机上看过；文字书 2026-10-08 改成「只修复」后，掌阅看过五本，Kindle、Move 还没在真机上看。逐条见[验证情况](docs/typesetting.md#验证情况)。
- 自带阅读器之间不能同步阅读进度（两台都不装 KOReader，见[设备 · KOReader](docs/devices.md#koreader)）。
- 带 DRM 的书拒收（解 DRM 暂停，见[开发 · DRM](docs/development.md#drm)）。
