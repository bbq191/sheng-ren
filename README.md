# 电子书入库与按阅读模式优化工具

在电脑上把 EPUB 和 CBZ 漫画收进一个**书库**，再按阅读器的屏幕特点**生成优化过的书**（Kindle 是 AZW3，其余是 EPUB），自己拷到设备上读。

![总体流程](docs/img/overview.svg)

- **收书**：EPUB、CBZ 漫画、网页链接能入库。书库**只存索引**（原件在哪、内容哈希、书名作者），不复制原件，几十本书的书库只有几百 KB。同一本书重复入库、改名移动都认得出来。
- **文字书**：去掉书里写死的字体、字号、行高，设备上调字号字体才能生效；按中文或英文的阅读习惯排版；注释比正文小一号；章标题独立一页，节与节、节与章之间分页，目录里节缩进挂在章下面。
- **漫画**：保留原画质，按阅读器真实的可阅读范围裁边、缩放、补白，黑白屏转 256 级灰度（不抖动），夹在漫画里的文字页照常保留。CBZ、EPUB 漫画都行。
- **没有封面的书联网补封面**：豆瓣中文版封面 → 原作封面（Wikidata + Open Library）→ 都没有就生成（书名 + 作者头像）。原件不动。
- **跟着书目录走**：登记跟踪书目录后，新书、改过的书自动同步进书库，产物按阅读模式放在书目录旁边、镜像原来的子目录，只重建有变化的书。

> 书里的文字一个不多、一个不少，图片还是原来那张（只为适配屏幕缩放），作者的强调（颜色、加粗）保留。拿不准的情况就不处理。

## 阅读模式

每种阅读器一个**阅读模式**（profile），一个模式出一份产物。三个模式都是设备自带的阅读器，用同一套优化规则，只是阅读范围、黑白彩色、产物格式不同：

| 模式 | 给谁读 | 产物 |
|---|---|---|
| `kindle` | Kindle Paperwhite 12 代签名版自带阅读器 | AZW3 |
| `ireader` | 掌阅 iReader Ocean 5 Pro 自带阅读器 | EPUB |
| `xochitl` | reMarkable Paper Pro Move 自带阅读器 | EPUB（彩色） |

Kindle USB 传书只认 AZW3，所以 `kindle` 模式先按同一套规则优化出 EPUB，再转成 AZW3（[AZW3 写出器](docs/azw3.md)）。
模式的配置、可阅读范围怎么量、加新模式，见[设备与可阅读范围](docs/devices.md)。

## 快速开始

需要 Rust 工具链（`cargo`）。

```sh
./install.sh                                  # 安装 booklib、ebook-meta 命令（卸载：./uninstall.sh）

booklib track ~/Documents/ereader/books       # 登记要跟踪的书目录（只需一次）
booklib sync                                  # 同步进书库，并按全部阅读模式生成
booklib list                                  # 看每本书的产物在哪、是否最新
```

跟踪 `~/Documents/ereader/books` 时，产物在它旁边的 `~/Documents/ereader/kindle/`、`ireader/`、`xochitl/`，子目录和 `books/` 里一样。
把这几个文件夹拷到对应的设备上即可（怎么拷，见[使用指南 · 传书到设备](docs/usage.md#传书到设备)）。
单个文件或网址用 `booklib add`，产物在书库的 `output/<模式>/` 下。完整用法见[使用指南](docs/usage.md)。

## 几个词

| 词 | 意思 |
|---|---|
| 书库 | 电脑上的一个目录（缺省 `~/.local/share/booklib`），只记每本书的原件在哪、内容哈希、书名作者、找来的封面，不复制原件 |
| 阅读模式（profile） | 一种阅读器的参数：屏幕、真实可阅读范围、黑白还是彩色、产物格式、注释怎么看。一个模式出一份产物 |
| 可阅读范围 | 阅读器除去页边距、页眉页脚后真正显示内容的区域，漫画按它缩放补白（见[设备与可阅读范围](docs/devices.md)） |
| 产物 | 按某个阅读模式优化出来的书，放在书目录旁边的 `kindle/`、`ireader/`、`xochitl/` 里，拷到设备上读 |
| 指纹 | 决定产物要不要重建的一串值（原件哈希、规则版本、模式参数……），任何一项变了才重建 |
| 质量门 | 产物生成后的自检（XHTML 合法、目录和图片引用都找得到、有没有 DRM）；没过只警告 |

## 现状

- **真机验证**：2026-09-30 用现在的产物在 Kindle、掌阅上看过文字书（字号字体、分页、目录、注释跳转）✓；Move 上验证过漫画左右离屏幕 1px、数字注释标号能跳，
  文字书排版还没看。逐条情况见[排版与优化规则 · 验证情况](docs/typesetting.md#验证情况)。
- **漫画离屏幕边缘 1px**：三台各用一种办法（Kindle 写成固定版式、掌阅漫画改往左翻、Move 页边距设成 1），2026-09-30 三台真机都做到了。见[排版与优化规则 · 离屏幕边缘 1px](docs/typesetting.md#离屏幕边缘-1px三台各一种做法)。
- 三台之间**不能同步阅读进度**（没有互通的接口；Kindle 的进度能读不能写，见[设备 · 阅读进度](docs/devices.md#阅读进度能不能在三台之间同步2026-09-30-真机实测)）。
- 带 DRM 的书拒收（解 DRM 暂停，见[开发](docs/development.md#drm)）。
