# 决定记录

用户定过的事，按日期排。正文里只写现状，需要理由时链到这里。后来推翻了的标"已改"，以最新的为准。

## 一直有效的约束

| 定了什么 | 为什么 |
|---|---|
| 只用 Rust，不用 Calibre（含 `ebook-convert`、DeDRM、KFX 插件） | — |
| clean-room：格式读写、解 DRM 只照公开文档和对样本的黑盒分析，不读不移植 GPL 代码 | 产物不能变成 GPL 衍生作品 |
| 书的内容一个字不多一个字不少；图片只为适配屏幕缩放；拿不准就不处理 | 这是"优化"不是"改书" |
| 漫画在黑白屏上转 256 级灰度，不抖动；按真实可阅读范围缩放补白 | 抖动是多一层损失，设备自己会换算 |
| 命令按功能命名；书里的 CSS 类用 `eink-` 前缀 | `sheng-ren` 只是开发代号 |
| 不按上传上限拆卷（原来的拆卷功能已删） | — |

## 2026-09-29

| 定了什么 | 为什么 |
|---|---|
| 只做 EPUB→EPUB：输入只收 EPUB、CBZ；PDF、MOBI/FB2 转换、直投设备都删掉 | 收窄范围 |
| 产物放在跟踪目录旁边，镜像子目录 | 拷到设备时整个文件夹拷（理由是推断的，待用户确认） |
| 产物一律升级到 EPUB 3 | 统一格式（xochitl、掌阅真机看过没问题） |
| 注释标号后不再加 ` [N]` | 严格说是多了字符 |
| 只解开字体、字号、行高的锁，别的样式不动；不再把灰字改黑、细字加粗 | 改颜色字重不是解锁 |
| 注释比正文小一号（0.85em），每条不拆到两页 | 五号→小五；一条注释要在同一页里看完 |
| 漫画"1px 边距"指图到**屏幕边缘**的距离，不是到可阅读范围边缘 | 阅读器自己的留白要算进去 |
| JPEG 只做无损的哈夫曼表重做，不换会改像素的编码器 | 画质不变 |
| 只有图标的注释标号在 xochitl 换成上标数字（Kindle、掌阅也先用数字） | xochitl 里只有图的链接点不了、CSS 限不住图标。数字是多出的字，但不这样就点不了 |
| Move 漫画的页边距登记暂不自动化，每次拷完手工跑 `comic-margins.sh --write` | 装在 Move 系统分区上风险大、系统更新会冲掉；备选是电脑上的 systemd 用户定时器 |
| Move 上不用 KOReader | 屏幕刷新由 xochitl 控制，翻页闪得厉害 |

## 2026-09-30

| 定了什么 | 为什么 |
|---|---|
| 撤掉 KOReader，三台都用自带阅读器；`koreader` 模式删掉 | "不好用，还是原生简洁"（**2026-10-02 已改**：Kindle、掌阅又用回 KOReader，但不恢复 `koreader` 模式） |
| 恢复 EPUB→AZW3：Kindle 出 AZW3，规则和 EPUB 完全一致（先优化出 EPUB 再转） | Kindle 自带阅读器 USB 传书只认 AZW3 |
| 网上的图抓不到就删掉这个 `<img>` | 设备不联网，留着只是断图 |
| 失效的样式（数字标号模式下的图标限高）从样式表删掉 | 用不上的规则不留 |
| 掌阅的漫画一律往左翻，日漫也是 | 往右翻的书掌阅铺不满整屏，用户选铺满 |
| `meta --fetch` 跳过漫画 | 漫画书里的封面就是第一页，按书名搜漫画多半对不上 |
