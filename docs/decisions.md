## 一直有效的约束

| 定了什么 | 为什么 |
|---|---|
| 只用 Rust，不用 Calibre（含 `ebook-convert`、DeDRM、KFX 插件） | — |
| 许可证：KindleUnpack、Calibre、DeDRM_tools、KFX Input 是 GPL，不读不移植，照它们写的讲解（deepwiki 等）也不看；Koodo Reader 是 AGPL-3.0，只借鉴它用哪些数据源、不看不抄代码；许可证事实要下载 LICENSE 确认 | 同上 |
| clean-room：格式读写、解 DRM 只照公开文档和对样本的黑盒分析，不读不移植 GPL 代码 | 产物不能变成 GPL 衍生作品 |
| 书的内容一个字不多一个字不少；图片只为适配屏幕缩放；拿不准就不处理 | 这是"优化"不是"改书" |
| 漫画在黑白屏上转 256 级灰度，不抖动；按真实可阅读范围缩放补白 | 抖动是多一层损失，设备自己会换算 |
| 命令按功能命名；书里的 CSS 类用 `eink-` 前缀，样式表叫 `eink-wash.css`，优化标记 `META-INF/eink-optimized`；仓库里不出现上游项目名及其两字母缩写 | `sheng-ren` 只是开发代号 |
