# 决定记录

用户定过的事，按日期排。正文里只写现状，需要理由时链到这里。后来推翻了的标"已改"，以最新的为准。

## 一直有效的约束

| 定了什么 | 为什么 |
|---|---|
| 只用 Rust，不用 Calibre（含 `ebook-convert`、DeDRM、KFX 插件） | — |
| 许可证：KindleUnpack、Calibre、DeDRM_tools、KFX Input 是 GPL，不读不移植，照它们写的讲解（deepwiki 等）也不看；Koodo Reader 是 AGPL-3.0，只借鉴它用哪些数据源、不看不抄代码；许可证事实要下载 LICENSE 确认 | 同上 |
| clean-room：格式读写、解 DRM 只照公开文档和对样本的黑盒分析，不读不移植 GPL 代码 | 产物不能变成 GPL 衍生作品 |
| 书的内容一个字不多一个字不少；图片只为适配屏幕缩放；拿不准就不处理 | 这是"优化"不是"改书" |
| 漫画在黑白屏上转 256 级灰度，不抖动；按真实可阅读范围缩放补白 | 抖动是多一层损失，设备自己会换算 |
| 命令按功能命名；书里的 CSS 类用 `eink-` 前缀，样式表叫 `eink-wash.css`，优化标记 `META-INF/eink-optimized`；仓库里不出现上游项目名及其两字母缩写 | `sheng-ren` 只是开发代号 |
| 不按上传上限拆卷（原来的拆卷功能已删） | — |

## 2026-09-29

| 定了什么 | 为什么 |
|---|---|
| 只做 EPUB→EPUB：输入只收 EPUB、CBZ；PDF、MOBI/FB2 转换、直投设备都删掉 | 收窄范围 |
| 产物放在跟踪目录旁边，镜像子目录 | 拷到设备时整个文件夹拷（理由是推断的，待用户确认） |
| 产物一律升级到 EPUB 3 | 统一格式（xochitl、掌阅真机看过没问题） |
| 注释标号后不再加 ` [N]` | 严格说是多了字符 |
| 只解开字体、字号、行高的锁，别的样式不动；不再把灰字改黑、细字加粗 | 改颜色字重不是解锁 |
| 注释比正文小一号（0.85em），每条不拆到两页 | 五号→小五；一条注释要在同一页里看完 |
| 漫画"1px 边距"指图到**屏幕边缘**的距离，不是到可阅读范围边缘 | 阅读器自己的留白要算进去 |
| JPEG 只做无损的哈夫曼表重做，不换会改像素的编码器 | 画质不变 |
| 只有图标的注释标号在 xochitl 换成上标数字（Kindle、掌阅也先用数字） | xochitl 里只有图的链接点不了、CSS 限不住图标。数字是多出的字，但不这样就点不了 |
| Move 漫画的页边距登记暂不自动化，每次拷完手工跑 `comic-margins.sh --write` | 装在 Move 系统分区上风险大、系统更新会冲掉；备选是电脑上的 systemd 用户定时器 |
| Move 上不用 KOReader | 屏幕刷新由 xochitl 控制，翻页闪得厉害 |

## 2026-10-05

| 定了什么 | 为什么 |
|---|---|
| 做 EPUB → KFX 写出器（clean-room：只照 Ion 公开规范和样本黑盒分析），推翻 09-27 的"KFX 不考虑" | 要 Kindle 自带阅读器的增强排版；KOReader 打不开 KFX，Kindle 读这类书回到自带阅读器 |
| 正文和批注不用嵌入字体，批注比正文小一号（0.85em）；其余内容（章名、卷名、书信等）可以用书里嵌入的字体。KFX、掌阅、Move 的 EPUB 统一按这条 | 正文跟阅读器设置走；装饰字体还原原书样子 |
| 「正文」＝全书覆盖字数最多的那个字体；「批注」＝注释块（class/epub:type 含 note、footnote，多看注释）、以「注：」「注1：」「按:」「批注」这类开头的段落（「注」「按」后可跟编号）、自己用了书里**嵌入的**单独字体且被括号包住的行内元素（系统字体名的括号文字不算：真书回归里《飘》的心理旁白、外文原名会被误缩小）；系统字体名（楷体、黑体等，没嵌文件的）照旧去掉 | 用户选的通用认法（《绍宋》：正文宋体，批注 kuohao 的括注和「注：」段落、脚注） |
| 中文书的 KFX 元数据语言写 `en`，正文样式里的语言不变 | Kindle 只按元数据语言开「段间距、字间距、字符间距」设置，中文书不开（Amazon 自己转的也不开）；中文排版不受影响。代价：长按查词默认弹牛津，要手动切到现代汉语词典 |
| 分页与目录按**目录层级**统一（合集书和普通书一样）：先定哪一级是「章」——目录最上一层如果是一本本书或部、卷（下面挂着章），它是「书/卷」级，下一层是章，否则最上一层就是章；书/卷级标题独占一页；章级标题独占一页（章名是普通段落的也算，如《绍宋》的装饰图加「第一章」「明道宫」两段），章名只是数字（「1」「2」）时和正文同页；节级（章的下一层）另起一页、标题和正文同页；更深的不分页；目录按这几级嵌套 | 原来按 HTML 标题级别判断，合集多一层「书/卷」、章名常写成普通段落，同一级时而独占一页时而不（金庸 467 回只有 244 独占、福尔摩斯 130 章 25、绍宋 481 章 34） |
| `ireader` 模式注释改成弹窗 | 真机《春雪》弹窗版：掌阅自带阅读器点标号弹出小窗，章末注释照常显示 |
| `kindle` 模式改出 KFX（先是文字书，漫画暂出 AZW3；KFX 固定版式真机通过后漫画也出 KFX，书库不再出 AZW3） | KFX 有注释弹窗、段间距字间距可调；固定版式漫画真机铺满整屏（《哆啦A夢》《死亡筆記》） |
| 背景图在 kindle、ireader 保留（profile 的 `background_images`），`background` 简写拆成分项，ireader 再去掉尺寸和 `fixed`；xochitl 照旧去掉 | 用户要两台都显示背景图；掌阅不认简写、`background-size` 把图挤变形（真机对照书），xochitl 会平铺满页盖住正文 |
| KFX 正文字体没嵌入时不写字体名 | Kindle 遇到不认识的字体名会换成别的字体，《啸风山庄》正文和表格字体不一样；正文本来就该用阅读器的字体 |
| KFX 列表、表格、边框的对照样本：Send to Kindle 发合成的测试书，取回 Amazon 转出的 KFX | 6 本样本里没有列表符号、表头、rowspan、各种边框样式；测试书只含合成文字 |
